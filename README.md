# MusicFree WebDAV 插件

这是一个用于 [MusicFree](https://github.com/maotoumao/MusicFree) 音乐播放器的 WebDAV 插件，允许你播放存储在 WebDAV 服务器上的音乐文件。

## 功能特性

- 🔍 **搜索功能**: 在 WebDAV 服务器上搜索音乐文件
- 📁 **歌单导入**: 将 WebDAV 目录作为歌单导入
- 🎵 **多种格式支持**: 支持 mp3, flac, wav, aac, ogg, m4a, wma, ape, opus 等格式
- 📝 **歌词支持**: 自动查找同名的 .lrc 歌词文件
- 📂 **递归扫描**: 自动递归扫描子目录中的音乐文件

## 安装方法

1. 下载 `webdav.js` 文件
2. 在 MusicFree 应用中，进入「侧边栏 → 设置 → 插件设置」
3. 点击「从本地安装插件」，选择下载的 `webdav.js` 文件
4. 安装完成后，在插件列表中找到 WebDAV 插件，点击进入配置页面

## 配置说明

安装插件后，需要配置以下信息：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| WebDAV服务器地址 | 你的 WebDAV 服务器 URL | `https://example.com/webdav` 或 `http://192.168.1.100:5005` |
| 用户名 | WebDAV 登录用户名 | `admin` |
| 密码 | WebDAV 登录密码 | `password` |
| 基础路径 | 音乐文件存放的基础路径 | `/music` 或 `/` |

## 使用方法

### 导入歌单

1. 在 MusicFree 中，进入「歌单」页面
2. 点击「导入歌单」
3. 选择 WebDAV 插件
4. 输入 WebDAV 目录路径，例如：`/music/我的歌单`
5. 插件会自动扫描该目录及其子目录下的所有音频文件

### 搜索音乐

1. 在 MusicFree 中使用搜索功能
2. 选择 WebDAV 作为搜索源
3. 输入关键词搜索

## 文件命名建议

为了更好地识别歌曲信息，建议按照以下格式命名文件：

```
艺术家 - 标题.mp3
```

例如：
- `周杰伦 - 晴天.mp3`
- `Taylor Swift - Love Story.flac`

如果文件名不符合此格式，插件会将整个文件名作为歌曲标题。

## 歌词支持

插件会自动查找与音乐文件同名的 `.lrc` 歌词文件。例如：
- 音乐文件：`/music/周杰伦 - 晴天.mp3`
- 歌词文件：`/music/周杰伦 - 晴天.lrc`

## 支持的音频格式

- MP3 (`.mp3`)
- FLAC (`.flac`)
- WAV (`.wav`)
- AAC (`.aac`)
- OGG (`.ogg`)
- M4A (`.m4a`)
- WMA (`.wma`)
- APE (`.ape`)
- OPUS (`.opus`)

## 注意事项

1. **网络访问**: 确保 MusicFree 应用能够访问你的 WebDAV 服务器
2. **认证方式**: 目前支持基本的用户名/密码认证
3. **性能考虑**: 如果音乐文件较多，首次扫描可能需要一些时间
4. **路径格式**: 所有路径请以 `/` 开头，例如 `/music/songs`

## 常见问题

### Q: 插件提示 "WebDAV未配置"
A: 请先在插件设置中配置 WebDAV 服务器地址、用户名和密码。

### Q: 无法播放音乐
A: 请检查：
- WebDAV 服务器地址是否正确
- 用户名和密码是否正确
- MusicFree 是否能够访问该网络地址

### Q: 导入歌单时提示 "目录中没有找到音频文件"
A: 请检查：
- 路径是否正确
- 该目录下是否有支持的音频格式文件
- 基础路径配置是否正确
